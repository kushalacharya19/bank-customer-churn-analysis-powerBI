# Bank Customer Churn Analysis — Power BI

## Project Overview

This project analyzes customer churn patterns in a banking dataset containing 10,000 customer records. An interactive two-page Power BI dashboard was developed to understand customer churn, retention, and high-risk customer segments.

## Objectives

* Analyze the overall customer churn rate.
* Identify customer segments with higher churn rates.
* Analyze churn across geography, age, credit score, balance, and number of products.
* Compare churn based on gender, credit-card ownership, and customer activity.
* Build an interactive dashboard using Power BI and DAX.
* Generate business insights that can support customer retention analysis.

## Tools & Technologies

* Power BI
* DAX
* Microsoft Excel / CSV
* Data Cleaning & Transformation
* Data Visualization
* Business Intelligence

## Dashboard Features

### Page 1 — Banking Customer Churn Analytics

The overview dashboard includes:

* Total Customers
* Churned Customers
* Retained Customers
* Churn Rate
* Geography filter
* Gender filter
* Active Member filter
* Credit Card filter
* Churn analysis by Geography
* Churn analysis by Age Group
* Churn analysis by Credit Score
* Churn analysis by Number of Products
* Churn analysis by Balance Group
* Churn analysis by Gender
* Churn analysis by Active Member
* Churn analysis by Credit Card ownership

### Page 2 — Customer Churn Insights

The detailed analysis page focuses on:

* High-risk age groups
* Credit-score segments
* Number of products
* Geographical churn patterns
* Active vs inactive customers
* Gender-based churn
* Key business insights

## Key Insights

* Overall customer churn rate is 20%.
* Germany has the highest churn rate among the analyzed geographical regions.
* Customers aged 66–70 show the highest churn rate.
* Customers with lower credit-score ranges show comparatively higher churn.
* Inactive members have a higher churn rate than active members.
* Customers with 3–4 products show comparatively higher churn rates.
